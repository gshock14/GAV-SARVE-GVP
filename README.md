## 🌐 GitHub वर सॉफ्टवेअर थेट लाईव्ह कसे चालवावे? (GitHub Pages Guide)

> **महत्त्वाची नोंद:** GitHub वर `index.html` फाईलवर क्लिक केल्यावर फक्त कोड (Code) दिसतो. ती फाईल प्रत्यक्ष वेबसाईटसारखी चालवण्यासाठी खालीलप्रमाणे **GitHub Pages** सुरू करावे लागते:

### GitHub Pages सुरू करण्याचे ३ सोपे टप्पे:
1. तुमच्या GitHub रेपॉझिटरी (Repository) मध्ये जा.
2. वर **Settings** (⚙️) पर्यायावर क्लिक करा.
3. डाव्या बाजूच्या मेनूमधील **Pages** या पर्यायावर क्लिक करा.
4. **Branch** खाली **`main`** (किंवा `master`) निवडा आणि फोल्डर **`/(root)`** निवडून **Save** बटण दाबा.
5. १ मिनिटात तुम्हाला तुमची लाईव्ह लिंक मिळेल:
   👉 **`https://<तुमचे-युझरनेम>.github.io/<रेपॉझिटरीचे-नाव>/`**
6. ही लिंक तुम्ही कोणत्याही मोबाईलवर किंवा कॉम्प्युटरवर उघडू शकता, संपूर्ण सॉफ्टवेअर थेट सुरू होईल!

## 🌟 ठळक वैशिष्ट्ये (Key Features)

1. **निर्माता सन्मान**:
   - सॉफ्टवेअरचे **निर्माता: श्री गणेश विलास पष्टे** यांचे नाव मुख्य हेडर, फुटर, अबाउट सेक्शन आणि शासकीय प्रिंट/पीडीएफ अहवालांवर प्रामुख्याने नमूद आहे.

2. **एकच स्वयंपूर्ण फाईल (Single-File Self-Contained)**:
   - संपूर्ण CSS, JavaScript, ड्रॉपडाउन्स आणि डिझाईन **`index.html`** मध्ये एकत्रित (Inlined) केले आहे.
   - तुम्ही GitHub वर फक्त `index.html` अपलोड केले तरीही संपूर्ण सॉफ्टवेअर कोणत्याही त्रुटीशिवाय १००% चालते.

3. **मोबाईल-फ्रेंडली डेटा फीडिंग (Mobile Data Feeding)**:
   - कुटुंब प्रमुख निवडताच पुढील कुटुंब आयडी आपोआप तयार होतो.
   - एकाच कुटुंबातील पुढील सदस्य नोंदवताना आडनाव, जात, रेशन कार्ड, घराचा प्रकार आपोआप भरला जातो.
   - जन्म तारीख निवडताच चालू वय आपोआप मोजले जाते.

4. **मोबाईल कार्ड व्ह्यू व शासकीय नोंदवही (Page View & Table View)**:
   - मोबाईलवर वाचायला सोपी कार्ड्स, थेट फोन कॉल (`tel:`) बटण.
   - अधिकृत १६ स्तंभांनुसार शासकीय नोंदवही टेबल (लँडस्केप व्ह्यू).
   - नाव, आधार, मोबाईल, कुटुंब आयडी, वयोगट व शाळाबाह्य मुलांनुसार तात्काळ शोध.

5. **एक्सेल व A4 प्रिंट सुविधा**:
   - मूळ `Gav_Ani_Shala_Survey_Nondvahi.xlsx` च्या रचनेत Excel डाऊनलोड व अपलोड.
   - तिन्ही स्वाक्षरी ब्लॉक्ससह A4 लँडस्केप प्रिंट किंवा थेट PDF सेव्ह करण्याची सोय.

## 🚀 स्थानिक पातळीवर (Local / Offline) कसे चालवावे?

### पद्धत १: १-क्लिक सुरू करणे (`start.bat`)
- फोल्डरमधील **`start.bat`** वर डबल-क्लिक करा.
- कॉम्प्युटरवर `http://localhost:3000` सुरू होईल आणि स्क्रीनवर दाखवलेला मोबाईल आयपी (उदा. `http://192.168.0.102:3000`) वापरून तुम्ही मोबाईलवरही वापरू शकता.

### पद्धत २: थेट ब्राऊझरमध्ये
- **`index.html`** वर राईट-क्लिक करून Chrome किंवा Edge मध्ये उघडा. इंटरनेट नसतानाही संपूर्ण ॲप चालेल.
